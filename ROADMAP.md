# RedminStore Upgrade Notes And Roadmap

Date: 2026-05-02, updated 2026-05-08

## Completed Today

RedminStore was upgraded from an old Laravel 5.1 Bootstrap/Grunt package into a Laravel 12 storefront package using modern Laravel frontend tooling.

### Package And Laravel Upgrade

- Updated `composer.json` for PHP 8.2, Laravel 12, Inertia Laravel, PHPUnit 11, Orchestra Testbench 10, and current Mockery.
- Added a local Composer path repository for `../redminportal` with symlink support.
- Added Laravel package auto-discovery for `Redooor\Redminstore\RedminstoreServiceProvider`.
- Replaced legacy route inclusion with `loadRoutesFrom`.
- Added modern route definitions in `routes/web.php`.
- Kept package view and translation namespaces under `redminstore::`.
- Added publish tags for package views and public assets.
- Removed legacy `illuminate/html`, Orchestra Imagine, Bootstrap alias, and manual autoloader registration from this package.

### Frontend Modernization

- Removed Grunt, Bower, Less, Bootstrap 3, jQuery, Redmaterials, Glyphicons, and old compiled CSS/JS assets.
- Added Vite, Tailwind CSS, PostCSS, Vue 3, and Inertia Vue 3.
- Added production asset output under `src/public/build`.
- Added an Inertia root Blade view at `src/resources/views/app.blade.php`.
- Added a small asset helper so the package can load Vite dev-server assets or built package assets.

### Storefront MVP

- Replaced the Blade-only pages/posts frontend with an Inertia SPA storefront.
- Added public routes for:
  - `/`
  - `/page/{slug}`
  - `/post/{slug}`
  - `/products`
  - `/products/{product}`
  - `/categories/{category}`
- Added catalog behavior backed by RedminPortal models:
  - Home page with featured active products plus recent public pages/posts.
  - Product index with active products, category filter, and pagination.
  - Product detail with price, SKU, descriptions, primary image, category, and variants.
  - Category detail with active products and active bundles.
  - Inertia 404 page for missing, invalid, private, or inactive content.

### Tests And Documentation

- Rebuilt Testbench setup for Laravel 12 and the local RedminPortal package.
- Added feature tests for home, public/private CMS content, invalid slugs, product visibility, inactive product rejection, and category filtering.
- Updated README with Laravel 12 installation, local RedminPortal setup, frontend build commands, routes, and testing.
- Updated UPGRADE.md with removed legacy tooling and new architecture.
- Updated CONTRIBUTING.md to reference Vite/Vue/Tailwind sources instead of old Less assets.

### Verified

- `composer validate --strict`
- `npm run build`
- `composer test`

Current test result: 8 tests, 97 assertions.

## Laravel 13 Compatibility Update

On 2026-05-08, the package constraints were widened so RedminStore can support Laravel 13 while continuing to work with Laravel 12 projects that use RedminPortal 2.

- `laravel/framework` now allows `^12.0 || ^13.0`.
- PHP now allows `^8.2 || ^8.3`; Laravel 13 installations still require PHP 8.3 or newer through Laravel's own constraint.
- `orchestra/testbench` now allows `^10.0 || ^11.0`.
- `phpunit/phpunit` now allows `^11.5 || ^12.5`.
- `redooor/redminportal` now allows `^2.0 || ^3.0`.

The local development stack was then upgraded and verified on:

- PHP 8.3.29
- Laravel Framework 13.8.0
- RedminPortal 3.0.0 from the local `../redminportal` path repository
- Orchestra Testbench 11.1.0
- PHPUnit 12.5.24

Verification remained green: `composer validate --strict`, `composer test`, and `npm run build`.

## Current Caveats

- This is a catalog MVP only. It does not include cart, checkout, payment, coupons, customer accounts, order creation, shipping, or tax flows.
- Product image support uses the first RedminPortal image path when available and falls back to a neutral placeholder.
- The package now uses RedminPortal 3.x through the local `../redminportal` path repository during Laravel 13 development.
- Laravel 12 support remains available through Composer constraints, but the checked-in lockfile is currently on the Laravel 13 dependency set.
- On case-insensitive filesystems, the facade directory rename from `src/facades` to `src/Facades` may need careful staging in Git.
- Server-side rendering is not configured for Inertia.
- The visual design is intentionally simple and example-oriented.
